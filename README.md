# Projeto POO
Este projeto foi desenvolvido no âmbito da unidade curricular Programação Orientada a Objetos no ano letivo 2025/2026,
com o objetivo de desenvolver uma solução em linguagem C# para problemas 
reais de complexidade moderada. Serão identificadas classes, definidas estruturas de 
dados e implementados os principais processos que permitam suportar essas soluções.

## Contexto do problema
Pretende-se desenvolver um projeto que permita gerir obra de construção civil, um sistema que permite controlar e gerir custos de uma determinada obra.

## Estrutura de diretórios do projeto
```
poo-tp-obras/
│
├── docs/       # Documentação de código
├── src/        # Código fonte
└── README.md   # Documentação do projeto
```

## Comandos
A partir da raiz do projeto pode executar os seguintes comandos:

### Execução do programa
```bash
cd src/GereObra
dotnet run
```

### Gerar documentação doxygen
```bash
cd docs/Doxygen
doxygen Doxyfile
```
